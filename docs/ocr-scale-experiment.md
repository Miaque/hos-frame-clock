# OCR 放大实验记录

日期：2026-09-14。13 张原始截图，每种倍率各调用两次，共 78 次真实 AI Studio PP-OCRv6 请求。

## 方法

固定裁剪横向 80%–98%、纵向 0%–12%，转 RGB，按原尺寸、LANCZOS 2 倍、3 倍编码 PNG。第一轮倍率顺序 1/2/3，第二轮 3/2/1，串行调用。使用允许日期时间之间零空白的解析器，任务参数和默认 10 秒超时保持一致。耗时包含图片准备和识别，不含实验产物写盘。

基准由画面人工核对；33d2 样图月份按用户明确确认的 OCR 结果 08 记录。原图不提交，仅保留文件名、SHA256 和无凭据的 OCR 原文及测量结果。

## 决策与边界

采用裁剪后统一 LANCZOS 3 倍放大，保持单次任务提交，不加入失败重试或字符猜测纠正。测试示例保存同样的上传图片。

3 倍平均上传大小约为原图裁剪的 5.76 倍。13 张样图不代表所有画面；重复调用不是独立样本，服务耗时波动也不是单纯缩放开销。仍可能有漏识别、错误数字或超时。

逐次记录见 [JSON 数据](ocr-scale-results.json)。复现实验须从原始截图裁剪；0.2.1 的 _crop 已含 3 倍缩放，不应再对其输出叠加实验倍率。
